# Level ২: বিষয়ভিত্তিক সিলেবাস কাঠামো

> বিষয় → মূল বিষয় (Main Topic) → উপবিষয় (Subtopic)। প্রতিটি মূল বিষয়ের ভেতরে উপবিষয়গুলো শেখার স্বাভাবিক ক্রমে সাজানো (মৌলিক ধারণা আগে, প্রয়োগ পরে; ইতিহাস ও সাহিত্য কালানুক্রমে; “অন্যান্য” সবার শেষে)। বন্ধনীর অক্ষর ৫২তম Priority ধাপ (A সবচেয়ে গুরুত্বপূর্ণ)। উপবিষয়ের নাম ও অবস্থান Level ২-এর ডাটাবেস অনুযায়ী অপরিবর্তিত।
