# Hostinger-এ সাইট live করা — সহজ ধাপ

## আগে বোঝার বিষয়: দুটি অংশ
| অংশ | কোথায় থাকে | কী আছে |
|---|---|---|
| **কোড ও গবেষণার ডেটা-ফাইল** | GitHub → Hostinger | পাতা, নিয়ম, ৫,৩৫২টি বিগত প্রশ্ন ও Current Affairs-এর ফাইল |
| **চলমান ডেটাবেস** | Hostinger-এর নিজের **MariaDB** (একই সার্ভার) | শিক্ষার্থীর অ্যাকাউন্ট, অগ্রগতি, ফলাফল, আপনার পরে দেওয়া প্রশ্ন |

ডেটাবেস অ্যাপের পাশেই, তাই সাইট দ্রুত; বাইরের কোনো সেবা (Neon ইত্যাদি) লাগে না। প্রতি ডেটাবেসে ৩ GB — প্রায় ১,০০০–২,০০০ সক্রিয় শিক্ষার্থী।
**প্রথম Deploy-এ অ্যাপ নিজেই** টেবিল বানায়, গবেষণার সব ডেটা ও Current Affairs বসায় (প্রায় আধা মিনিট) এবং প্রথম অ্যাডমিন তৈরি করে। কম্পিউটার থেকে কিছু চালাতে হয় না।

## ধাপ ১ — MariaDB ডেটাবেস (৩ মিনিট)
1. hPanel → **Databases → MySQL Databases** (Hostinger-এ এটি MariaDB 11.8)।
2. ডেটাবেসের নাম, ব্যবহারকারী ও শক্ত পাসওয়ার্ড দিয়ে **Create**। Hostinger নামের শুরুতে একটি উপসর্গ যোগ করে (যেমন `u123456789_bcs52`) — পুরো নামটি লিখে রাখুন।
3. `DATABASE_URL` হবে: `mysql://<ব্যবহারকারী>:<পাসওয়ার্ড>@localhost:3306/<ডেটাবেসের নাম>`
   - host সাধারণত `localhost`; hPanel-এ অন্য কিছু দেখালে সেটি দিন।
   - পাসওয়ার্ডে `@ : / # ?` থাকলে URL-encode করুন (যেমন `@` → `%40`), অথবা এসব চিহ্ন ছাড়া পাসওয়ার্ড দিন।
   - কাউকে দেবেন না, চ্যাটেও না। Remote MySQL চালু করার দরকার নেই।

## ধাপ ২ — ইমেইল (পাসওয়ার্ড রিসেটের জন্য)
hPanel → Emails → আপনার ডোমেইনে একটি মেইলবক্স, যেমন `no-reply@<ডোমেইন>`, পাসওয়ার্ড দিয়ে তৈরি করুন।
SMTP-র ঠিকানা/পোর্ট hPanel-এর ইমেইল সেটিংয়ে মিলিয়ে নিন (সাধারণত `smtp.hostinger.com`, `465`)।

## ধাপ ৩ — GitHub-এ বিল্ড (একবার সেটআপ)
Hostinger-এর সার্ভারের Linux পুরোনো (GLIBC ২.২৯-এর নিচে), তাই সেখানে Next.js ১৬-এর compiler চলে না।
সমাধান: **বিল্ড হয় GitHub-এ** (`.github/workflows/hostinger-build.yml`), তৈরি অ্যাপ যায় **`deploy`** শাখায়; Hostinger শুধু সেটি চালায়
(চালাতে compiler লাগে না — compiler সরিয়ে রেখে পরীক্ষা করা হয়েছে)।

GitHub → `BCS` repo → **Settings → Secrets and variables → Actions → New repository secret** — একটি:

| নাম | মান |
|---|---|
| `APP_URL` | `https://<আপনার ডোমেইন>` |

(বিল্ড ডেটাবেস ছোঁয় না, তাই GitHub-এ ডেটাবেসের ঠিকানা দিতে হয় না। আগে `DATABASE_URL` secret দিয়ে থাকলে মুছে দিন।)

তারপর repo → **Actions → Build for Hostinger → Run workflow** (প্রথমবার; পরে `main`-এ প্রতিটি push-এ নিজে চলে)। সবুজ ✓ হলে `deploy` শাখা তৈরি হয়।

## ধাপ ৪ — Hostinger-এ অ্যাপ
hPanel → Websites → **Add website → Node.js Apps → Import Git repository** → GitHub যুক্ত করুন → `BCS` repo।

| সেটিং | মান |
|---|---|
| Framework | Next.js |
| Branch | **`deploy`** (main নয়) |
| Node.js version | 22 (না থাকলে 20) |
| Build command | `npm run build` |
| Start | Hostinger নিজে চালায় (দিতে হলে `npm run start`) |

**Environment variables** — এখানে বসান:

| নাম | মান |
|---|---|
| `DATABASE_URL` | ধাপ ১-এর MariaDB ঠিকানা |
| `APP_URL` | `https://<আপনার ডোমেইন>` (শেষে `/` নয়) |
| `ADMIN_EMAIL` | আপনার অ্যাডমিন-ইমেইল |
| `ADMIN_PASSWORD` | শক্ত পাসওয়ার্ড (১০+ অক্ষর) — প্রথম Deploy-এর পর মুছে দেবেন |
| `SMTP_HOST` | `smtp.hostinger.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `no-reply@<ডোমেইন>` |
| `SMTP_PASS` | ঐ মেইলবক্সের পাসওয়ার্ড |
| `MAIL_FROM` | `বিসিএস ৫২ প্রস্তুতি <no-reply@<ডোমেইন>>` |
| `NEXT_PUBLIC_MAX_UPLOAD_MB` | `4` |

সহজ উপায়: `platform/.env.hostinger` ফাইলের `<…>` অংশগুলো পূরণ করে **Import .env** দিয়ে সব একসঙ্গে বসান।

**Deploy** চাপুন। প্রথমবারের বিল্ড-লগে দেখবেন:
`[deploy-setup] গবেষণার ডেটা বসানো হচ্ছে…` → `ব্যর্থ: কিছু নয়` → `Current Affairs প্রশ্নব্যাংক বসানো হলো: 138টি` → `প্রথম অ্যাডমিন তৈরি`।
পরের Deploy-গুলোতে: `গবেষণার ডেটা সম্পূর্ণ (5352 প্রশ্ন, 467 ধাপ)`। মাঝপথে থেমে গেলে আবার Deploy করুন — যা আছে তা রেখে বাকিটা বসায়।

## ধাপ ৫ — ডোমেইন, SSL, যাচাই
1. ডোমেইন অ্যাপের সঙ্গে যুক্ত করুন, SSL চালু করুন।
2. `https://<ডোমেইন>/api/health` → `{"ok":true,"db":"ok",…}`
3. `/login`-এ অ্যাডমিন-ইমেইল ও পাসওয়ার্ডে ঢুকে `/admin` খুলুন।
4. Hostinger → Environment variables থেকে **`ADMIN_PASSWORD` মুছে** Redeploy করুন।
5. নিজের একটি শিক্ষার্থী-অ্যাকাউন্ট খুলে "পাসওয়ার্ড ভুলে গেছি" দিয়ে ইমেইল আসে কিনা দেখুন।

## পরে প্রশ্নভান্ডার দেওয়া — GitHub লাগে না
প্রশ্ন ডেটাবেসে থাকে, তাই **শুধু সাইটের অ্যাডমিন প্যানেল থেকে**:
1. **Import** → CSV/Excel ফাইল (প্রতিটি ৪ MB-এর মধ্যে; বড় হলে বিষয় অনুযায়ী ভাগ) → পূর্বরূপ → Import (খসড়া হিসেবে)।
2. **প্রশ্ন** → খসড়া প্রশ্ন দেখে নির্বাচন করে **প্রকাশ করুন** → সেই মুহূর্তে শিক্ষার্থীর Level ২-এ চলে আসে।
3. ব্যাখ্যা যাচাই।
4. **Model Test** → খসড়া তৈরি → দেখে অনুমোদন।

অ্যাডমিন প্যানেলের প্রথম পাতায় **"নতুন প্রশ্ন কীভাবে live হয়"** অংশে এই চারটি ধাপ আর প্রতিটির বর্তমান অবস্থা (কতটি হলো, কতটি বাকি) দেখায়।
ফাইলের গঠন: `docs/QUESTION_IMPORT.md`; কোন উপবিষয়ে কতটি: `docs/level2_targets.csv`।

## Current Affairs প্রশ্নব্যাংক হালনাগাদ — GitHub লাগে না
প্রথম Deploy-এ `data/source/current_affairs.docx` (সংস্করণ ১.০, ১৩৮ প্রশ্ন) নিজে থেকে বসে। নতুন সংস্করণ এলে:
অ্যাডমিন → **Current Affairs** → .docx বাছাই → পূর্বরূপ (ত্রুটি/সতর্কতা দেখায়) → Import।
একই নম্বরের প্রশ্ন হালনাগাদ হয় (শিক্ষার্থীর অগ্রগতি থাকে; প্রশ্ন বা উত্তর বদলালে শুধু সেই প্রশ্নের অগ্রগতি মোছে), নথিতে নেই এমন প্রশ্ন নিষ্ক্রিয় হয়।
নথির কাঠামো একই রাখতে হবে: অধ্যায় ৩ (প্রশ্ন), ৫ (উত্তর ও ব্যাখ্যা), ৬ (Quick Revision), ৭ (তথ্যসূত্র)। তথ্য যাচাইয়ের তারিখ ৪৫ দিনের বেশি পুরোনো হলে শিক্ষার্থীরা সতর্কবার্তা দেখে।

## কোড বদলালে (আমি কিছু ঠিক/যোগ করলে)
কোড `main`-এ push হয় → GitHub Actions কয়েক মিনিটে বিল্ড করে `deploy` শাখা হালনাগাদ করে (Actions-এ সবুজ ✓ দেখুন) → Hostinger-এ **Redeploy** (স্বয়ংক্রিয় চালু থাকলে নিজেই)। ডেটাবেসের নতুন পরিবর্তনও তখন নিজে থেকে প্রয়োগ হয়; শিক্ষার্থীর অগ্রগতি ও আপনার প্রশ্ন অক্ষত থাকে।

## Backup
অ্যাডমিন → Backup থেকে নিয়মিত (সপ্তাহে অন্তত একবার) ফাইল ডাউনলোড করে রাখুন। hPanel → Backups-এ Hostinger-এর ডেটাবেস-Backup-ও আছে; ডেটাবেসের আকার hPanel-এ দেখা যায় (সীমা ৩ GB)।

## সমস্যা হলে
- **বিল্ড ব্যর্থ, ডেটাবেসের ত্রুটি** → `DATABASE_URL`-এর ব্যবহারকারী, পাসওয়ার্ড (বিশেষ চিহ্ন URL-encode) ও ডেটাবেসের পুরো নাম (উপসর্গসহ) মিলিয়ে দেখুন।
- **লগে "কোনো অ্যাডমিন নেই"** → `ADMIN_EMAIL`, `ADMIN_PASSWORD` (১০+ অক্ষর) দিয়ে Redeploy।
- **সাইট চালু হয় না, "APP_URL নেই"** → `APP_URL` দিয়ে Redeploy।
- **রিসেট-ইমেইল আসে না** → SMTP মান ও মেইলবক্সের পাসওয়ার্ড।
- বিল্ড-লগের লেখা কপি করে আমাকে পাঠালে বলে দেব কী করতে হবে (পাসওয়ার্ড/ঠিকানা থাকলে মুছে দিন)।
