# টপিকভিত্তিক প্রশ্ন Import-এর ফাইল-গঠন

CSV (UTF-8, প্রথম সারিতে কলামের নাম) অথবা JSON (বস্তুর তালিকা)।

| কলাম / কী | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| `subtopic_code` | হ্যাঁ | যেমন `BN.BH.SHD` — তালিকা: `/research` পাতার Priority List |
| `question` | হ্যাঁ | প্রশ্নের লেখা |
| `option_a` … `option_d` (JSON-এ `options: [..4..]`) | হ্যাঁ | চারটি ভিন্ন অপশন |
| `answer` | হ্যাঁ | `ক`/`খ`/`গ`/`ঘ`, `A`–`D`, `১`–`৪`, অথবা সঠিক অপশনের হুবহু লেখা |
| `explanation` | না (দৃঢ়ভাবে প্রস্তাবিত) | বিস্তারিত ব্যাখ্যা |
| `difficulty` | না | `easy`/`medium`/`hard` বা `সহজ`/`মাঝারি`/`কঠিন` (Level 3-এর কঠিনতা-মিশ্রণে লাগবে) |
| `source` | না | তথ্যের উৎস (বই, সরকারি ওয়েবসাইট …) |
| `question_type` | না | যেমন সরাসরি তথ্য, প্রয়োগ, হিসাব |
| `uid` | না | না দিলে `T-<উপবিষয়>-0001` ধাঁচে নিজে তৈরি হয় |

## কী হয়

- **ত্রুটিপূর্ণ সারি** (অজানা কোড, অপশন কম/একই, উত্তর বোঝা যায় না) বাদ পড়ে; সারি নম্বরসহ তালিকা দেখায়।
- **হুবহু পুনরাবৃত্তি** (একই লেখা ও অপশন, অপশনের ক্রম যা-ই হোক) — ডেটাবেসের যেকোনো প্রশ্ন বা একই ফাইলের আগের সারির সঙ্গে — বাদ পড়ে।
- **প্রায়-একই প্রশ্ন** (একই উপবিষয়ে ৮০% বা বেশি মিল): "সামান্য পরিবর্তিত সংস্করণ" হতে পারে, তাই
  খসড়া (DRAFT) হিসেবে আসে, সঙ্গে কোন প্রশ্নের সঙ্গে মিল তার টীকা। অ্যাডমিন দেখে রাখবেন বা মুছবেন।
- ডিফল্ট অবস্থা **DRAFT** — যাচাই করে প্রকাশ না করা পর্যন্ত শিক্ষার্থীর পথে আসে না।
